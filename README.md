# PruebaGCO
Esta prueba contiene un formulario de inscripción para un programa de fidelidad de GCO en donde los usuarios se pueden registrar para acceder a los beneficios asociados a cada una de las marcas de la empresa.

## Prerequisitos
Docker

## Ejecución
`docker compose up --build`  
Abrir el siguiente enlace en el navegador: http://localhost:5173/

## Tecnologías
- Python
- SQLAlchemy
- Flask
- SQLite
- React + Vite
- Docker
